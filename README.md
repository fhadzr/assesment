# V-TEKI Technical Assessment

Three runnable, tested, and reproducible AI/ML prototypes (Fraud Risk Prediction, Document Intelligence, Enterprise RAG Chatbot), built spec-driven with [OpenSpec](https://github.com/Fission-AI/OpenSpec). All datasets are synthetic; all metrics come from executable scripts; nothing is marked verified without an actual artifact.

## Prerequisites

- **Python ≥ 3.10** on PATH (`python --version`)
- **make**:
  - Windows: MinGW make (`mingw32-make`, e.g. via [MinGW](http://mingw.org/) or `choco install make`) or Git Bash's make
  - macOS/Linux: build-essential / Xcode tools
- No internet needed for tests: the suite runs offline with mock providers only.

## Quick start

```bash
make setup     # creates .venv per case (case1_fraud, case2_docintel, case3_rag)
make test      # runs each case's tests + root convention tests, per-case venv
make check     # data + evidence/security convention checks
```

Single case:

```bash
make setup-case1 && make test-case1
```

Clean everything (venvs, caches):

```bash
make clean
```

## Without make (raw commands)

```bash
python -m venv case1_fraud/.venv
case1_fraud/.venv/Scripts/python -m pip install -e case1_fraud -r case1_fraud/requirements.txt   # Windows
# case1_fraud/.venv/bin/python ...                                                              # macOS/Linux
case1_fraud/.venv/Scripts/python -m pytest case1_fraud/tests tests -q

python scripts/check_data_conventions.py
python scripts/check_evidence_conventions.py
```

## Layout

| Path | Purpose |
| --- | --- |
| `case1_fraud/` | Fraud Risk Prediction — `data/ src/ tests/ outputs/ docs/` (package: `fraud`) |
| `case2_docintel/` | Document Intelligence — `samples/ expected/ src/ tests/ outputs/ docs/` (package: `docintel`) |
| `case3_rag/` | Enterprise RAG Chatbot — `data/ src/ tests/ outputs/ docs/` (package: `rag`) |
| `scenarios/` | The six critical thinking scenarios |
| `evidence/` | Traceability matrix, `experiment_log/`, `security_test_results/`, `cost_analysis/` |
| `docs/conventions/` | Synthetic-data, evidence, and security conventions |
| `scripts/` | Convention checkers and setup helpers |
| `report/source/` | Report source material |
| `openspec/` | Spec-driven changes and specs |
| `AI_DISCLOSURE.md` | AI tool usage disclosure |

## Conventions

- **Dependencies are isolated per case** — each case has its own venv and pinned `requirements.txt`; cases never import each other.
- **Synthetic data only** — generated by seeded checked-in scripts ([conventions](docs/conventions/synthetic-data.md)).
- **Evidence lives under `evidence/`** and is verified against the [traceability matrix](evidence/assessment_traceability.csv) ([conventions](docs/conventions/evidence.md)).
- **No secrets in source** — automated scan in `make check-evidence` ([conventions](docs/conventions/security.md)).
- Planning artifacts live in `openspec/changes/<name>/`; see `CLAUDE.md` for the workflow.
